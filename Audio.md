# Audio

Lab | Audio is a lightweight audio inspector for iPhone, iPad and Mac. Open any audio file and instantly see what's inside: format, channels, sample rate and duration, alongside a scrolling spectrogram that shows how the sound's frequencies change over time. Play, pause and skip 15 seconds either way while a playhead tracks your position across the spectrogram.

## Features

* Load a single audio file from the Files app
* File details at a glance: format, channels, sample rate and duration
* Scrolling spectrogram of the whole file
* Transport controls with a live playhead
* Light, dark or system appearance
* Optional anonymous usage stats, which you can switch off in Settings. File names and audio content are never collected.
